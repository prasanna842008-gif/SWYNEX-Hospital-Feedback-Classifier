SWYNEX Hospital Feedback Classifier

Project Overview

This project focuses on classifying hospital feedback using Python and machine learning.

Project Files

- "app.py" – Main application
- "model.py" – Model implementation
- "dataset.csv" – Dataset
- "requirements.txt" – Required Python libraries

Technologies Used

- Python
- Machine Learning
- Pandas

Installation

Install the required libraries:

pip install -r requirements.txt

Run the Application

python app.py
